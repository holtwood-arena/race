# ahc — AtCoder Heuristic Contest 历届题

入口：https://atcoder.jp/contests/archive?ratedType=0&category=1200 （Heuristic 分类）

AHC 是"没有最优解"的优化赛：限时（通常 4h~2 周）内产出尽量好的解，由得分排名。
历届题全部可补交评分，适合练"有限时间内的算法权衡"。日本社区 writeup 极详细。

## 使用方式

- 每场一个子目录：`ahc0XX/`，内含题面链接、初版解、改进记录（`PERF.md`）
- 与 speed-demon 的区别：这里比"解的质量"而非"常数时间"，两者互补
- 建议从经典入门题开始：AHC001（圆形排布）、AHC011（15-puzzle 类）等社区教程多的场次
